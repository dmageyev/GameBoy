# games

Цей каталог містить чотири ігри для GameBoy (Arduino Nano).

## Ігри

| Каталог          | Гра                          |
|------------------|------------------------------|
| `snake/`         | Змійка                       |
| `tetris/`        | Тетріс                       |
| `pong/`          | Понг                         |
| `space_invaders/`| Космічні загарбники          |

## Структура версій

Кожна гра має власні версії у підкаталогах (наприклад, `v1/`, `v2/`), що дозволяє відстежувати етапи розробки:

```
games/
└── <назва_гри>/
    ├── v1/          ← перша версія (початкова реалізація)
    ├── v2/          ← друга версія (нові можливості / виправлення)
    └── README.md    ← опис гри та журнал змін
```
