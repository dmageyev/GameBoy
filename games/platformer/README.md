# Platformer — Платформер

Гра «Платформер» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Стрибайте по платформах, збирайте предмети та перемагайте ворогів, щоб дістатися до фінішу рівня.

## Керування

| Кнопка | Дія             |
|--------|-----------------|
| ←      | Рух вліво       |
| →      | Рух вправо      |
| A      | Стрибок         |
