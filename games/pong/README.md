# Pong — Понг

Класична гра «Понг» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Відбивайте м'яч ракеткою і не давайте йому вилетіти за межі екрану. Перший гравець, який набере 10 очок, перемагає.

## Керування

| Кнопка | Дія                 |
|--------|---------------------|
| ↑      | Ракетка вгору       |
| ↓      | Ракетка вниз        |
