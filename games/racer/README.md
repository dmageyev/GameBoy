# Racer — Гонки

Гра «Гонки» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                             |
|--------|----------------------------------|
| v1     | Початкова версія гри (після 1-го)|
| v2     | Наступна версія гри  (після 2-го)|
| Final  | Фінальна версія гри  (після 3-го)|

## Правила гри

Керуйте автомобілем, уникайте перешкод та інших машин на дорозі. Чим далі ви проїхали — тим вищий рахунок.

## Керування

| Кнопка | Дія             |
|--------|-----------------|
| ←      | Рух вліво       |
| →      | Рух вправо      |
