# Racer — Гонки

Гра «Гонки» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Керуйте автомобілем, уникайте перешкод та інших машин на дорозі. Чим далі ви проїхали — тим вищий рахунок.

## Керування

| Кнопка | Дія             |
|--------|-----------------|
| ←      | Рух вліво       |
| →      | Рух вправо      |
