# Snake — Змійка

Класична гра «Змійка» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Керуйте змійкою, збирайте їжу та уникайте зіткнень зі стінами і власним тілом.

## Керування

| Кнопка | Дія         |
|--------|-------------|
| ↑      | Рух вгору   |
| ↓      | Рух вниз    |
| ←      | Рух вліво   |
| →      | Рух вправо  |
