# Space Invaders — Космічні загарбники

Класична гра «Космічні загарбники» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Знищуйте хвилі ворожих прибульців, які рухаються до Землі. Уникайте їхніх снарядів і захищайте планету.

## Керування

| Кнопка | Дія                    |
|--------|------------------------|
| ←      | Рух вліво              |
| →      | Рух вправо             |
| A      | Постріл                |
