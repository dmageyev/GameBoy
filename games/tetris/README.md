# Tetris — Тетріс

Класична гра «Тетріс» для GameBoy (Arduino Nano).

## Версії

| Версія | Опис                         |
|--------|------------------------------|
| v1     | Початкова реалізація гри     |

## Правила гри

Укладайте падаючі фігури (тетроміно) у горизонтальні лінії без пропусків. Заповнена лінія зникає і нараховуються очки.

## Керування

| Кнопка | Дія              |
|--------|------------------|
| ←      | Рух вліво        |
| →      | Рух вправо       |
| ↓      | Прискорення      |
| A      | Поворот фігури   |
