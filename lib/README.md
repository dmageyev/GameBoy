# lib

Цей каталог містить бібліотеки Arduino, які використовуються в проекті.

## Структура

Кожна бібліотека розміщується у власному підкаталозі:

```
lib/
├── <НазваБібліотеки>/
│   ├── src/
│   └── README.md
└── README.md
```

## Встановлення бібліотек

Скопіюйте необхідні бібліотеки з цього каталогу до папки `libraries` Arduino IDE або використовуйте їх безпосередньо через відносні шляхи у скетчах.
