# system

Цей каталог містить єдину систему з головним меню, яке об'єднує всі чотири гри GameBoy (Arduino Nano).

## Призначення

Головна програма відображає меню вибору гри та запускає відповідну гру.

## Ігри у меню

1. Snake — Змійка
2. Tetris — Тетріс
3. Pong — Понг
4. Space Invaders — Космічні загарбники

## Структура версій

```
system/
├── v1/           ← перша версія (базове меню)
│   └── gameboy.ino
├── v2/           ← друга версія (покращене меню / нові функції)
└── README.md
```
